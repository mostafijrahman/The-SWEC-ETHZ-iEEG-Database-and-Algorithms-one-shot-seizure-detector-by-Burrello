===============================================================================
 SWEC-ETHZ Short-term Dataset - Replication of the LBP + HD seizure detector
 (Burrello et al., IEEE BioCAS 2018)  -  one-notebook version
===============================================================================

Project : MSc CS thesis, LSU Shreveport - "Localization of Epileptic Seizures"
Author  : Mostafij Rahman
Source  : http://ieeg-swez.ethz.ch/  (Short-term Dataset and Algorithms)
Paper   : A. Burrello, K. Schindler, L. Benini, A. Rahimi, "One-shot Learning for
          iEEG Seizure Detection Using End-to-end Binary Operations: Local Binary
          Patterns with Hyperdimensional Computing", IEEE BioCAS 2018
          (arXiv:1809.01926).

The notebook  SWEC_LBPHD_replication.ipynb  repeats, in one file, every step
that was run on the lab PC (VS Code terminal + scripts, 1-6 October 2026):

  Step 1   Settings and machine check
  Step 2   Project folders, VS Code settings, .gitignore, requirements.txt
  Step 3   Install Python packages (PyTorch, SciPy, ...)
  Step 4   Git repository (optional)
  Step 5   Download dataset + original ETH code (optional, skipped if present)
  Step 6   Verify the dataset (16 patients, 100 seizure files)
  Step 7   Install the Python 3 / PyTorch 2 version of LBP+HD + self-test
  Step 8   Train and test LBP+HD for every patient   (LONG: ~2 days on CPU)
  Step 9   Rebuild summary.csv + metrics under the paper's protocol
  Step 10  Compare with the paper's Tables I-II and with the lab run, plot

The ported LBP+HD code is embedded in the notebook (Step 7), so nothing else
has to be copied from the lab PC except the dataset.


-------------------------------------------------------------------------------
1. REQUIREMENTS
-------------------------------------------------------------------------------
- Windows 10/11 (other systems work; change ROOT in Step 1)
- Python 3.11  (3.10 / 3.12 should also work; NOT 3.13+, because numpy<2 has
  no packages for it)
- VS Code with the "Python" and "Jupyter" extensions (Microsoft), or Jupyter
- Git (optional, for the change history)
- Disk: ~12 GB for the unpacked data (+ ~12 GB more if the notebook downloads
  the zips), plus ~1 GB for results
- An NVIDIA GPU is optional. Without one everything runs on the CPU
  (lab PC: no GPU, full run ~2 days).

-------------------------------------------------------------------------------
5. SETTINGS (first code cell of Step 1)
-------------------------------------------------------------------------------
  ROOT            project folder               default C:\Users\mrahman\sEEG
  DOWNLOAD_DATA   download the dataset zips      default False
  DOWNLOAD_CODE   download the original ETH code default True (reference only)
  FOLD_MODE       "full"     = exactly the lab run: sliding k-fold for every
                               patient, 679 seizure tests, ~2 days on CPU
                  "original" = only what the paper's tables need, 246 tests,
                               ~2.8x faster; paper-protocol results identical
  SEED            hypervector random seed        default 1 (authors' value)
  RUN_PATIENTS    paper patient numbers to run   default all 16, smallest first
  RERUN_EXISTING  re-run finished patients       default False
  USE_GIT         keep a Git history             default True

The scripts also read these environment variables (set by the notebook):
  SWEC_ROOT, SWEC_FOLDS, SWEC_SEED, SWEC_PATIENT ("6", "1,2,3" or "all"),
  SWEC_GPU (GPU index), SWEC_ID_MAP (force direct|transform|inverse),
  SWEC_ORIGINAL_TRAIN_INDEX=1 (reproduce the original training-index bug),
  SWEC_FAST=0 (use the original, slower encoder; results identical).

-------------------------------------------------------------------------------
7. WHAT THE TWO RESULT TABLES MEAN
-------------------------------------------------------------------------------
summary.csv (released-code metrics, = what HD_PostProcessing.py prints)
  Averages over every recording in every fold, INCLUDING the seizures used for
  training.

LBPHD_replication_vs_BioCAS2018.csv (paper protocol, use this for the thesis)
  Unseen seizures only. Table I patients (1,2,4,5,6,8,11,13,15,16): k-fold.
  Table II patients (3,7,9,10,12,14): single split - train on the first m
  seizures, test on the rest. Columns: paper_* = published values, repl_* =
  this replication, released_* = released-code metrics.

-------------------------------------------------------------------------------
9. CHANGES FROM THE AUTHORS' ORIGINAL CODE (all marked "PORT:" in the code)
-------------------------------------------------------------------------------
  1. Python 2.7 -> 3.11 and old PyTorch -> PyTorch 2; runs on CPU or any GPU
     (the original required CUDA GPU #1 of the ETH server).
  2. The released training and post-processing scripts used different file
     names, folders and fold counts and could not run together; they now
     share swec_config.py.
  3. Bug fix: from the 2nd fold on, training read seizure i+1+cross but took
     the ictal times of seizure i+1. Fixed; SWEC_ORIGINAL_TRAIN_INDEX=1 restores
     the original behaviour.
  4. Patient numbering resolved (paper numbers vs dataset folders),
     checked against the seizure counts.
  5. A vectorised HD encoder gives bit-identical output to the original
     sample-by-sample loop (checked in Step 7); SWEC_FAST=0 uses the original.
  6. One progress line per seizure instead of one per half second; division by
     zero guarded when nothing is detected.
  7. Metrics: summary.csv keeps the released definition; the paper protocol
     (unseen seizures only, single split for Table II) is computed separately
     by paper_protocol_metrics.py.


-------------------------------------------------------------------------------
10. TROUBLESHOOTING (problems met on the lab PC)
-------------------------------------------------------------------------------
"No module named scipy" / packages go to Python313
    The notebook kernel is not the .venv. Select the .venv kernel (section 4)
    and rerun Step 3.

"Found no NVIDIA driver on your system"
    Only appears with the ORIGINAL scripts (torch.cuda.set_device). The ported
    scripts use the CPU automatically. Rerun Step 7 to restore them.

PermissionError ... summary.csv
    summary.csv is open in Excel. Close it and rerun Step 9 (nothing is lost;
    predictions are saved).

"git is not recognized"
    Install Git (section 2.1) and restart VS Code, or set USE_GIT = False.

A file named iEEGClassifierLBP_HD.py appears
    A browser renamed "+" to "_" when downloading. The notebook writes the
    correct name itself (Step 7); delete the "_HD" copy.

"Seizure-file counts ... do not match"
    Data missing or merged wrongly. Check Step 6 and the table in section 3.

Kernel died / PC restarted during Step 8
    Run Step 1, then Step 8b again: finished patients are skipped.

numpy 2.x found
    pip install "numpy<2" in the .venv, restart the kernel.
